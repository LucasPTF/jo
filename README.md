# Jô — As Chaves do Perdão

Landing page independente, convertida dos layouts originais do Elementor para HTML, CSS e JavaScript puros.

## Páginas

- `/angulo1` — abordagem “dor em silêncio”
- `/angulo2` — abordagem “entender por que ainda dói”
- `/angulo3` — abordagem “perdoar não é aceitar”

As três rotas compartilham a mesma estrutura e carregam a variação correta do bloco principal. O projeto não depende de WordPress ou Elementor.
